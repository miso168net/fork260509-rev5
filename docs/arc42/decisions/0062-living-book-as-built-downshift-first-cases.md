## 背景

ADR 0058 一次性放寬活書 §6／§8 配額並寫定停損：下次再撞頂不再調高、改走「as-built 下放
到碼註或新建之獨立文件、活書只留指針」；但該工項只住 ADR 內文、無待辦承載（B-126②），
且 §9／§11 兩節配額該不該動（B-126①、啟動書 §3.3 第 8 項「rev5 應重議」）與 §5 的同型
逼近皆列射程外。

2026-08-25 量測（取得指令＝`python3 tools/docs-sync.py lint` 尾行）：
§5 **85/90**｜§6 120/160｜§8 92/130｜§9 4/5｜§11 3/3。逐刀序列（取得指令＝ADR 0058
「為何是 §6／§8 而非別節」節之 awk 迴圈、節號各換 §5／§8）：§5＝3／13／35／61／70／75／85
（+10／刀）、§8＝17／37／60／73／77／89／92。

★三個改變處置方向的發現：

1. **§9／§11 不是逼近、是指針節**：活書原文 §9「決策全文住 docs/arc42/decisions/…本節不承載
   內容」、§11「待辦與候選 ☞ ops/BACKLOG；坑與防法 ☞ ops/LESSONS。本節不承載內容」。配額
   5／3 恰等於指針行數 ⇒ 它的作用是「有人往指針節塞內容即警告」，是正確的守門。刀 B 的
   新風險／新決策本來就落 BACKLOG／LESSONS／decisions，不會撞 §11／§9。
2. **刀 B 真正會撞的是 §5（餘 5 行），不是 §8**：ADR 0058 點名的首選標的（§8 接線段 45 行）
   是在 §8 89/90 時量的；放寬後 §8 餘 38、刀 B 預估 +8；搬 §8 解不了 §5（同 ADR 0058
   自述「只搬 §8 解不了 §6」）。
3. **§5 內有一段自承的抄本**：「src 側測試共用設施 `model::test_db`」清冊（自「＋src 側測試
   共用設施」之下一行起、至「顯式釋放））。」止，**18 行**）——活書自己寫「全文住該模組 doc」、
   各守衛「為何非有不可」逐條在其型 doc。依 CLAUDE.md §4「鏡像不是機器生成、就是不存在」，
   這段本就不該以第二份手抄形存在於活書；且測試設施不是架構面、最不該佔架構書的配額。

## 決定

1. **§8「fork-delta 接線現況」子節下放**：該子節 **45 行**（取得指令＝ADR 0058 替代案②之
   awk）逐位元搬到新檔 `docs/arc42/FORK-DELTA-WIRING.md`（**活書附屬文件**、現在式）；
   活書保留 `### fork-delta 接線現況（base-web）` 標題與一段指針（節號骨架不動）。
   搬運驗證＝兩側 awk 抽取後 diff 為空。
2. **§5 測試設施清冊下放**：上述 18 行下放到 `rust-api/server/src/model/mod.rs` 之 `test_db`
   模組 doc（該模組已是 sequence 兩套紀律與各守衛「為何非有不可」的家）；活書留一句指針。
   下放時名冊內每個名字與數字逐項 grep 復驗，復驗不到的數字不寫。
3. **`SECTION_QUOTAS` 整張不動**（釘值測 `test_section_quotas_pinned_by_adr` 零改動）：
   ADR 0058 款 3 的停損在本次以「下放」而非「調高」兌現；本 ADR 不 supersede ADR 0058
   任何條款。
4. **§9／§11 配額維持 5／3**：指針節的配額＝指針行數，是守門不是壓力；啟動書 §3.3 第 8 項
   「rev5 應重議」至此收束（重議結論＝維持）。
5. **附屬文件的治理面三處登記**：Lint07 `BUDGETS` 新列（**200 行 ERROR**、起始值）；Lint10
   時態閘與 Lint11 詞典閘的掃描面自「活書＋CLAUDE.md」擴為「活書＋附屬文件＋CLAUDE.md」
   （附屬文件名冊＝`docs-sync.py` 常數 `BOOK_ANNEXES`；自測釘「每本附屬文件必有預算列」）；
   README 文件地圖新節點。Lint12～15 走全 tracked md、自動涵蓋。
6. **取態改寫**：B-083 所記「活書＝現在式 as-built 單一家」改為「活書＝現在式架構敘事＋
   as-built **索引層**；清冊型 as-built 的單一家可在碼註（有單一碼家者）或活書附屬文件
   （跨檔者），活書只留指針」。「每個事實只有一個人寫的家」不變——變的是家可以不在活書。
7. **下放作業定型（日後任一節撞頂＝輕量軌、不再逐次 ADR）**：判準＝該段是碼註／機器真源
   的抄本、或每刀都長的清冊；去處＝碼註或 `docs/arc42/` 附屬文件、**絕不入 `specs/`**
   （ADR 0058 款 3）；程序＝逐位元搬運＋diff 為空、附屬文件登記三處（`BUDGETS`／
   `BOOK_ANNEXES`／README 地圖）、活書指針含 ADR 號。下一候選＝§5 觀測面序列清冊
   （→`obs.rs` 模組 doc）。

## 為何是這兩段

- **§8 接線段**：ADR 0058 已量測點名；每個 UI 刀都長（005→006 +12）；自有機器守
  （fork-delta-lint／view-render-guard／route-artifact-gate）；活書外引用面 2026-08-25 量測
  （取得指令＝`grep -rIn --exclude-dir=specs "接線現況" docs CLAUDE.md README.md .specify tools`）
  ＝零筆指向該子節（ADR 0053 之「活書 §8 授權慣例條目」指的是留下的子節）。現在做＝在
  平靜的維護批做結構搬遷；不做＝落在某個 UI 刀收尾撞 130 時搬（不該停手的時點）。
- **§5 測試設施清冊**：見背景第 3 點；18 行令 §5 餘裕自 5 升至約 20、刀 B 預估 +6～10 可容。
- **為何不是 §5 觀測面序列清冊**：對外觀測介面、屬架構面，留書；列為下一候選。

## 考慮過的替代案

- **①配額重分配**（§8 130→90、§5 90→130、總和 678 不變、不撞 700 硬底）：不採——必須改
  絆線測、推翻 ADR 0058 款 2「其餘十節一個字不動」；抄本仍留書內、+10／刀的成長沒被處理，
  只是把牆往後推四刀。
- **②只做 §5、§8 留待撞頂**：不採——搬遷會落在某個 UI 刀收尾，且取態變更只有單一實例。
- **③兩段都下放（含觀測面）**：現階段不採——觀測面屬架構面；§5 餘裕已夠刀 B。
- **④§9／§11 放寬**：不採——指針節。

## 後果

- lint 判準基線不變（0 錯誤／2 警告，該二警告＝CLAUDE.md 的 Lint11 既有命中）；§5 餘裕
  5→約 20、§8 餘裕 38→約 77（實測節行數記收單事件）。
- 多一本現在式文件要維護（預算／時態／詞典三閘同管）；fork-delta 接線 as-built 的家自此在
  附屬文件、活書只指路，閱讀路徑多一跳。
- 絆線測零改動、ADR 0058 全部條款仍有效；本 ADR 的射程止於「清冊型 as-built」——行為序、
  慣例、模組拓樸等架構敘事仍住活書。
- 改動面＝活書兩處、新檔一本、`docs-sync.py`（常數兩處＋run_lint 掃描面＋自測）、README
  一行、rust-api 一支模組 doc（pin bump 一次）、BACKLOG 刪 B-126。
