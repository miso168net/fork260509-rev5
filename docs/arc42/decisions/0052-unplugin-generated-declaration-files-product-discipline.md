## 背景

U11 首次引入 NTreeSelect 元件後，vite 的 unplugin-vue-components 自動重算
`base-web/src/typings/components.d.ts`（+2 行宣告）。該檔是 upstream 基線既有檔、
不在憲法 §III.2 用途 (ii) 的「定數恰 8 檔」名單內——字面上構成「名單外 base-web 既有檔
被動」。實質上它是機器生成檔：檔頭帶 `Generated by unplugin-vue-components` 標記、
內容由工具依模板掃描全量重算（逐行標記於下次重算即被抹除、物理上不可維持）、
`tools/fork-delta-lint.py` 之 `is_generated()` 據檔頭標記自動豁免——機器面早已把它當
產物檔對待，缺的只是憲法字面的補位。

## 決定

1. **unplugin 生成之元件宣告檔（`src/typings/components.d.ts` 同族、以檔頭 Generated
   標記為判準）併入產物檔紀律**——與憲法 §III.2 既有「路由外掛產物四檔」同款：由工具
   重算產出、**禁手改**、不逐行標記、不入任何用途檔級名單；其變更隨引入新元件的單元
   同 commit 帶入（重算觸發＝vite transform，主線可以請求該 SFC 模組 URL 觸發）。
2. 機器承載＝`fork-delta-lint` 之 `is_generated()` 檔頭判準（現行為即決定、零碼變更）；
   審查判準＝該檔 diff 只允許工具重算形（宣告行增刪）、出現手寫內容即紅線。
3. 憲法 §III 正文納入本條款＝隨下一次 Amendment（授權治理刀島 G 入憲時）順捎、不單獨
   bump 版本；在此之前本 ADR 為唯一權威。

## 後果

- 未來新元件首進場（生成檔重算）零爭議、零逐案拍板；U11 之 +2 行改動溯及追認。
- 「名單外 base-web 既有檔一律無授權」的硬邊界字面自此帶一個明文例外類（生成檔）；
  例外判準是機器可驗的檔頭標記、非人為裁量——硬邊界的精神（防手改滲漏）不減損。
